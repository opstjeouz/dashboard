# Setup Instructions

```bash
1. Create a new project folder, e.g., dashboard-sidebar. 2. Inside it, create the structure: index.html, css/style.css, js/script.js, assets/ (optional), README.md, .gitignore. 3. Copy the provided code into each file as described. 4. No package manager or build step is required. 5. Open index.html directly in a modern browser, or serve the folder with a static server for best results (e.g., npx serve . or python -m http.server 8000). 6. Ensure you have an internet connection the first time you load the page so the Boxicons CDN stylesheet loads; alternatively, download Boxicons locally and update the <link> in index.html. 7. Test responsiveness by resizing the browser or using dev tools device emulation.
```
